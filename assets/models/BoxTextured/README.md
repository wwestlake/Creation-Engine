# BoxTextured

Test/bring-up asset, not original content. Fetched from the Khronos Group's
[glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)
repository (`Models/BoxTextured/glTF/`) — the standard, permissively
licensed fixture set used across the industry for exercising a glTF
importer end to end (geometry, PBR material factors, external texture).

Used here to verify `Source/Render/Import/GltfLoader` against a real file
instead of only procedurally generated test geometry.
